# Editor panel and below-canvas controls refinement

- The **item editor panel** (opened by selecting an item on the Builder canvas) now has a fixed title/drag header and a separately scrolling content region. This lets users drag and close the editor without having to scroll to its top.
- Removed sticky behavior from the **website header**; it was not the intended target.
- **Run Simulation** now shares the same box and horizontal row as Takt Time, Scale, and Walking Speed below the canvas; the separate Simulation box was removed.
- No scenario structure or storage changes.
